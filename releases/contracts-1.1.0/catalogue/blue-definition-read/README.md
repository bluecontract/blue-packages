# Native definition-read capability

An explicitly selected execution protocol for reading an exact native definition
reference from the starting document. Generic operation generators use it to
preserve authored request matchers, including schema-only fields and `{}`, without
depending on a display description or inferring the shape of an action's input.

The 34 existing current packages remain the business catalogue acceptance scope.
This additional support package is an execution capability, not another business
operation family. Historical protocol and package identities remain unchanged.
