# Manual Payments

Manual Bank Payment creates one PI. The recipient accepts, the payer reports a stable transfer reference, and the recipient confirms actual receipt. Only that confirmation records payment. Full refund is requested by the recipient and confirmed received by the payer. It has no card authorization/capture request phase. These are attributable participant assertions, not independently bank-verified facts. Partial refunds and automatic bank reconciliation are outside this profile.

Unpublished candidate. Authored Blue/BEX definitions are authoritative. See ../docs/payment-family.md for the tested package selection and integration boundaries.
