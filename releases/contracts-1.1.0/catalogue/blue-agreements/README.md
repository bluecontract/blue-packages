# blue-agreements — composable edition

This edition uses the event-driven protocol from the matching Clauses package. The immutable `.blue` types define its behavior. Shared channels and embedding declarations are composed by the host; outgoing transition validation controls replacement and removal. Configuration remains in `/clauses`; no retired configuration archive is kept.
