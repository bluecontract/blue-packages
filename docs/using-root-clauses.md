# Selecting root-local clause packages

Read `ROOT-CLAUSE-PACKAGES.json` and pin the complete business edition. Its four
archives are independent of the 13-package baseline selection. Runtime consumers
must explicitly support the existing Language/BEX/Contracts/Coordination IDs;
these data archives do not register a native clause role.

Python Workbench uses `PackageStore.package(name,
edition='root-clause-bindings-20260929-1')`, with private authoring prefixes
RootAgreements, RootMutualActivation, RootImmediateTermination and RootReseller.
The minimal visible source uses `Reseller/Reseller Agreement`; this lesson's
selected edition resolves that display name to its exact type BlueId before
registration. The ordinary legacy source editor retains its existing Reseller
alias. No global alias is rebound and existing documents retain their exact
closure.

See [the edition](../editions/root-clauses/) for exact sources and locks. The four
foundation copies in that directory are unchanged supplied dependency archives.
A wheel or standalone Python source export bundles 17 archives: the baseline 13
plus these four. The packages repository's separate data bundle also includes
the Time preview, for 18 archives in total.
