# Offers

`Offers/Offer` is a plain commercial domain type, analogous to Agreement and Order. It identifies a proposition independently of its distribution channel or commercial model. It declares no fields, clauses or automatic execution. A specialization defines presentation, application inputs and the resulting process. Creating or distributing an Offer does not start that process.

This is an unpublished local candidate. Build with the repository native builder; installing its exact archive requires no public registry or release.
